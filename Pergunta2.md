- Pergunta: Indique uma situação no trabalho onde é retornada, ou faria sentido ser retornada, uma resposta
  HTTP com o status code 401 (Unauthorized) ou 403 (Forbidden)? Justifique porque foi tomada
  essa decisão.

- Resposta: O status code 401 retorna quando por exemplo um user tenta acessar um recurso protegido.
- O status code 403 retorna quando um user tenta acessar um recurso protegido, mas nao tem autorização para o acessar.

- Pergunta: No contexto do sistema de controlo de versões Git, explique qual é a diferença entre os
comandos add e commit, e indique situações concretas onde usou cada um dos comandos
durante a realização do projeto.

- Resposta: O comando "git add" é usado para adicionar arquivos ou alterações ao staging area, preparando estes ficheiros para o commit
Já o comando "git commit" é usado para criar um novo commit com as alterações que foram adicionadas ao staging area, ou seja salva as alterações no repositorio local.

O comando commit serve para guardar as alteraões realizadas localmente utilizando uma mensagem que descreva as alterações após a utilização
do comando add para adicionar os ficheiros alterados, já o comando push normalmente
é usado posteriormente e tem como objetivo enviar essas alterações para o repositório remoto.

Foi usado por exemplo ao fazer alterações a um ou vários ficheiros do projeto (commit) e
posteriormente foi feito push para o repositório remoto para partilhar as alterações
com os colegas.
